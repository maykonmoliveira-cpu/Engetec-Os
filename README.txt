ENGETEC OS - arquivos iniciais
1. Publique estes arquivos no repositório GitHub.
2. Execute supabase/schema.sql no SQL Editor do Supabase.
3. Em index.html, substitua SUPABASE_URL e SUPABASE_KEY pela Project URL e chave publishable.
4. Publique o site via GitHub Pages ou hospedagem estática.
A chave service_role/sb_secret nunca deve ser usada no navegador.
